# Vehicle asset credits

All included vehicle assets are original downloaded 3D meshes, not generated box proxies.

- **Quaternius — Realistic Car Pack (November 2018)**: `vehicles/quaternius/NormalCar1.fbx`, `NormalCar2.fbx`, `SUV.fbx`, `SportsCar.fbx`, `SportsCar2.fbx`, `Taxi.fbx`. Original pack: https://quaternius.com/packs/cars.html ; official download: https://quaternius.itch.io/lowpoly-cars .
- **Kenney — Car Kit**: `vehicles/kenney/delivery.glb`, `truck.glb`, `van.glb`, shared `Textures/colormap.png`. Original pack: https://kenney.nl/assets/car-kit ; official download: https://kenney-assets.itch.io/car-kit .

Both creators dedicate these assets under **CC0 1.0 Universal**: https://creativecommons.org/publicdomain/zero/1.0/ . Their original license texts are preserved in each vehicle folder. Attribution is appreciated, although not required by CC0.

Only selected models are included. The original FBX/GLB and texture bytes are unchanged. Rendering code may override paint/roughness/emission, normalize dimensions, rotate the model and animate its separate wheel objects. `mesh-notes.json` records source OBJ measurements to help align the imported FBX models; it is not a replacement 3D model.

`sources.json` records source pages, download date and SHA-256 hashes for the selected files and original archives. Downloaded archives and unused models remain outside the repository.
